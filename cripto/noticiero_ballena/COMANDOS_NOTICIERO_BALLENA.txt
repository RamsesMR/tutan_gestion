NOTICIERO BALLENA V1 — POWERSHELL
================================

EJECUTAR DESDE LA RAÍZ DE tutan_gestion EN LA RAMA dev2.

0) INSTALAR REQUISITOS
----------------------
python -m pip install -r cripto/noticiero_ballena/requirements_noticiero_ballena.txt

1A) HISTÓRICO OFICIAL DE WHALE ALERT
------------------------------------
# Descarga manualmente el archivo histórico desde la fuente oficial.
# Si contiene fecha de publicación, se usará. Si no, se aplica una latencia
# conservadora de 5 minutos.

python -m cripto.noticiero_ballena.importar_whale_alert `
  --entrada "RUTA\AL\ARCHIVO_HISTORICO.jsonl" `
  --latencia-minutos 5

1B) HISTÓRICO DE OTRO PROVEEDOR O ARCHIVO PROPIO
------------------------------------------------
python -m cripto.noticiero_ballena.normalizar_eventos `
  --entrada "RUTA\AL\ARCHIVO.csv" `
  --fuente "NOMBRE_PROVEEDOR" `
  --registro-entidades cripto/noticiero_ballena/config/entidades_verificadas.example.json


1C) ENRIQUECIMIENTO OPCIONAL CON ARKHAM
---------------------------------------
$env:ARKHAM_API_KEY="TU_CLAVE"

python -m cripto.noticiero_ballena.enriquecer_arkham `
  --entrada datos/cripto/preparados/noticiero_ballena/normalizados/eventos_ballena.parquet `
  --salida datos/cripto/preparados/noticiero_ballena/normalizados/eventos_ballena.parquet

2) AUDITAR EVENTOS
------------------
python -m cripto.noticiero_ballena.auditar_eventos

DETENERSE SI LA AUDITORÍA ES RECHAZADA.

3) GENERAR VARIABLES POR MINUTO
-------------------------------
python -m cripto.noticiero_ballena.generar_variables `
  --desde 2021-01-01 `
  --hasta 2025-01-01

4) CONTEXTO ON-CHAIN OPCIONAL
-----------------------------
# CryptoQuant. Requiere CRYPTOQUANT_API_KEY.
$env:CRYPTOQUANT_API_KEY="TU_CLAVE"

python -m cripto.noticiero_ballena.descargar_contexto_onchain `
  --proveedor cryptoquant `
  --desde 2021-01-01T00:00:00Z `
  --hasta 2025-01-01T00:00:00Z `
  --ventana hour `
  --exchange binance

# Integrar solo con el retraso real de publicación del proveedor.
python -m cripto.noticiero_ballena.integrar_contexto `
  --contexto datos/cripto/crudos/noticiero_ballena/cryptoquant_contexto.parquet `
  --retraso-minutos 0

5) ETIQUETAR CONTRA BTC 1M
--------------------------
# Puede recibir un archivo o una carpeta con varios Parquet.
python -m cripto.noticiero_ballena.etiquetar_impacto `
  --precios datos/cripto/preparados/corto_plazo_baja_v1

6) ENTRENAR Y GENERAR PREDICCIONES OOF
--------------------------------------
python -m cripto.noticiero_ballena.entrenar_modelo

7) EXPORTAR HISTÓRICO PARA FUTUROS MODELOS
------------------------------------------
python -m cripto.noticiero_ballena.exportar_para_modelos --modo historico
python -m cripto.noticiero_ballena.auditar_exportacion

DETENERSE AQUÍ Y REVISAR MÉTRICAS ANTES DE CONECTAR BAJA V3.
